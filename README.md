# Rebase

Private Mac notepad. One shared timeline. Three lanes: Ideas, Life, Work.

**Capture everything. Face only today.**

This is a just-for-me app. Local only. No account, no server, no GitHub.

## Run

```bash
cd ~/Desktop/Projects/rebase-mac
APP_NAME=Rebase BUNDLE_ID=com.zayd.rebase ./Scripts/compile_and_run.sh
```
